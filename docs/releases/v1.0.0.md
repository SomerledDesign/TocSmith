# TocSmith 1.0.0

TocSmith 1.0 (build 346) is the first public release. It forges a navigable
sidebar outline into PDFs that have a printed table of contents and a text
layer but no bookmarks, and leaves the source PDF untouched.

## Install

```sh
brew install SomerledDesign/tap/tocsmith
```

Or from a checkout (Python 3.9 or newer):

```sh
./tocsmith "/path/to/manual.pdf" --write-bookmarks
```

This writes `manual.bookmarked.pdf` and `manual.bookmarked.pdf.log.txt`. On
Windows, see the README.

## What it does

- Detects an extractable text layer and stops instead of guessing when there
  isn't one (scan-only documents need OCR first).
- Finds likely table-of-contents pages and extracts sections, subsections and
  appendices.
- Resolves printed TOC entries to the matching headings in the document,
  preferring heading text over printed page numbers.
- Writes a nested sidebar outline.
- Crops oversized pages only when there is credible crop-mark or PDF box
  evidence, normalises rotated pages, and adds a configurable footer
  watermark (`--watermark`, default `TocSmith`, `--watermark ""` for none).
- Writes a human-readable log explaining every accepted or skipped entry.
- Without `--write-bookmarks` or `--output`, prints a JSON analysis only.

## Notes

- Depends on `pypdf>=6.18.1,<7`.
- `man tocsmith` has the full command reference (installed by Homebrew).
- `toc-bookmarks` remains as a compatibility alias for `tocsmith`.
