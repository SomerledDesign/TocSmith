# TocSmith 1.1.1

Draft release notes. This version is not tagged, not published, and the
Homebrew tap is unchanged.

TocSmith 1.1.1 (build 349) stops replacing a good outline. A PDF that already
has bookmarks keeps them, including Title, Author, and the document language.
Contents rows are linked to those bookmarks. Tables of contents that print
chapter-page numbers (`7–4`, `A–1`, `Index–1`) in their own column are read
in order.

## Fixed

- **Crash on indirect page boxes.** Writing a PDF whose pages store
  `/MediaBox` as an indirect object (the LaserJet 6P/6MP service supplement
  does on 98 of its 214 pages) stopped with `AttributeError: 'NoneType'
  object has no attribute 'get_object'`. pypdf 6.18.1 resolves such a box
  through `page.pdf`, which is `None` on pages copied into a writer. The
  finisher now rewrites every page box as a direct rectangle first, taking
  an inherited `/MediaBox` from the page tree and assuming US Letter when
  none is usable. A page that still fails is left without a watermark, named
  in a warning and in the log (`SKIP page N`), and the rest of the file is
  finished.
- **Existing outlines.** `writer.append(..., import_outline=False)` was
  dropping the sidebar outline on every write. 1.1.0 turned the SuperCalc
  manual's 68 bookmarks into 15, nine of them aimed at the wrong page.
  The default is now to keep an outline when the source has one.
- **Metadata.** Title, Author, and catalog `/Lang` are copied into the
  finished file.
- **File size.** Watermarking left page content streams uncompressed, so a
  933 KB manual grew to about 4.6 MB. Streams are compressed after the
  footer is merged. The same command on the SuperCalc fixture stays under
  1.3× the input.
- **Contents links.** Links were added only for rows that became new
  bookmarks, and only on the first contents page when the reader reversed
  the columns. A separate link pass matches every contents row to an
  existing bookmark or named destination and reuses that destination.
- **Chapter-page contents.** Page numbers such as `7–4` and `Index–1` are
  resolved from the printed footer (or from `/PageLabels` when the file has
  one). Rows are ordered in page coordinates, and a page-number column is
  paired with titles by vertical overlap instead of being fused into the
  title.

## New flags

- `--outline keep|merge|replace`. `keep` is the default when the source has
  an outline. `merge` adds only generated entries that are missing.
  `replace` is the 1.1.0 behavior.
- `--links` / `--no-links`. Links are on by default. Existing links are kept,
  and a row that is already linked is not linked again.

The decision log records the outline mode and how many bookmarks were kept.

## Checked on the SuperCalc fixture

`tests/fixtures/SuperCalc_Manual.pdf` (56 pages, 68 two-level bookmarks,
112 named destinations, contents on pages iii and iv):

```sh
tocsmith SuperCalc_Manual.pdf --write-bookmarks --output SCM-writ.pdf --watermark Somerled.Design
```

| | 1.1.0 | 1.1.1 |
|---|---|---|
| Bookmarks | 15, 9 mistargeted | 68, same titles and pages |
| Contents links | 15, page iii only | 68 (51 sections and 17 chapter rows) |
| Title / Author / Lang | dropped | kept |
| Output size with watermark | about 4.6 MB | about 1.07× the input |

## Notes

- `--version` reports `TocSmith 1.1.1 (349)`.
- Link rectangles are still estimated from character counts.
- Not tagged. Do not publish a release or update the Homebrew tap from this draft.

## Dependencies

- Requires `pypdf>=6.21.4,<7` (was `>=6.18.1`). pypdf 6.18.1 cannot add the
  contents links 1.1.1 writes (its `add_annotation` expects an older
  destination form), and content-stream compression after watermarking did
  not keep the file size down. The Homebrew formula pins pypdf 6.21.4.
