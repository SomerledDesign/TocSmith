# TocSmith 1.1.0

TocSmith 1.1.0 (build 348) makes the printed table of contents clickable. When
it writes bookmarks, it now also places invisible links over the TOC entries
themselves, so clicking a line on the Contents page jumps to that section, the
same place as the matching sidebar bookmark.

## New

- **Clickable TOC entries.** With `--write-bookmarks` (or `--output`), each
  bookmarked TOC entry gets a borderless link annotation over its title text
  on the TOC page, pointing at the same page as its bookmark. Links are added
  only where the entry's position on the page is clear; uncertain entries are
  skipped rather than guessed. Links already present in the source PDF are
  kept.
- **Logged decisions.** The log gains a "TOC link annotations" section with a
  `LINK` or `SKIP` line per entry (TOC page, destination, rectangle, reason)
  and a total in the finishing summary.
- Link rectangles are computed in page coordinates (text matrix and CTM
  applied), so they land correctly on scanned PDFs drawn at scanner
  resolution and on PDFs that carry the font size in the text matrix. Long
  rows are kept to the visible page.

## Included from 1.0.1

- Outline children nest under the nearest shallower entry when TOC levels
  skip (e.g. a chapter followed directly by level-3 sections), instead of
  falling back to the root.
- The source archive includes `LICENSE` (GPL-3.0-or-later).

## Tested on

| Manual | Bookmarks | TOC links |
|---|---|---|
| 4DOS Reference Manual (scanned, 300 dpi) | 176 | 176 |
| MS-DOS 6.22 User's Guide | 166 | 166 |
| HP LaserJet 6P/6MP Service Manual | 101 | 101 |
| Mastering the Chess Openings, Vol. 3 | 48 | 48 |
| Blinky kit sample manual | 11 | 11 |

Every link points at the same page as its bookmark and sits on its TOC page.

## Notes

- Link widths are estimated from the character count (pypdf does not expose
  glyph widths), so a rectangle can end a character or two before or after
  the title.
- A TOC entry that wraps onto two lines is linked on the line that carries the
  page number.
- `--version` reports `TocSmith 1.1.0 (348)`.

## Install / upgrade
