# TocSmith 1.0.1

TocSmith 1.0.1 (build 347) is a bug-fix release.

## Fixed

- **Flat outlines when TOC levels skip.** When the layout pass assigned
  sections a deeper level than the next one down (for example chapters at
  level 1 followed directly by sections at level 3), the writer looked only
  for a parent exactly one level up, found none, and attached the sections to
  the root. Sections now nest under the nearest accepted shallower entry, so
  a manual like "Chapter 1 > 1.1, 1.2; Chapter 2 > 2.1 …" produces a nested
  sidebar outline again. A regression test covers the skipped-level case.

## Packaging

- The source archive now includes `LICENSE` (GPL-3.0-or-later). The 1.0.0
  archive predates the licence commit.
- `--version` reports `TocSmith 1.0.1 (347)`.

## Install / upgrade

```sh
brew update && brew upgrade SomerledDesign/tap/tocsmith
# or, first time:
brew install SomerledDesign/tap/tocsmith
```
